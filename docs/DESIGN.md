# EmbyAurora · 设计系统

## 定位

EmbyAurora 是一个「服务端注入派」的 Emby 前端美化方案。设计目标是：**把 Emby 变成一台属于用户自己的影院** —— 有明确的设计美学、可一键切换的多套风格、以及极致便捷的使用体验。

核心设计原则：**便捷优先**。

- 一键部署、自动识别版本与环境
- 零配置开箱即用（默认主题 + 核心功能，无需 API key）
- 网页内可视化设置（换主题 / 调色 / 开关，实时生效）

## 主题引擎

全部视觉由一组 **CSS 变量** 驱动。主题 = 变量的集合；换主题 = 换变量，DOM 结构零改动。

```css
:root {
  --aurora-bg;              /* 页面背景 */
  --aurora-bg-soft;         /* 次级背景 */
  --aurora-glass;           /* 玻璃/卡片底色 */
  --aurora-glass-strong;    /* 玻璃强底色 */
  --aurora-glass-border;    /* 玻璃描边 */
  --aurora-text;            /* 主文字 */
  --aurora-text-dim;        /* 次文字 */
  --aurora-accent;          /* 主色 */
  --aurora-accent-soft;     /* 主色弱化 */
  --aurora-gradient;        /* 渐变（关闭 = 纯主色，克制默认） */
  --aurora-font;            /* 标题字体 */
  --aurora-font-ui;         /* 界面字体 */
  --aurora-radius;          /* 圆角 */
}
```

三层应用：

1. `aurora.css` — 变量默认值（影幕黑金）+ 所有引用变量的组件样式
2. `themes/*.css` — 四套主题，仅覆盖变量
3. `settings.js` — 运行时直接改变量，实现网页内实时切换 + 持久化

## 四套主题

| 主题 | 主色 | 字体气质 | 圆角 | 渐变 |
|---|---|---|---|---|
| 影幕·黑金 cinema | `#c9a227` 香槟金 | 衬线（Georgia） | 3px | 关（纯色） |
| 雪白·极简 snow | `#0066cc` 蓝 | 细体系统字 | 16px | 关 |
| 深空·玻璃 space | `#7aa2ff` 冰蓝 | 系统无衬线 | 14px | 开 |
| 画报·编辑 poster | `#d8482a` 砖红 | 粗黑无衬线 | 0 | 关 |

**默认主题 = 影幕·黑金**：深色影院底色 + 香槟金细线，契合暗环境观影场景；克制细线回应「浮夸」反馈。

## 页面覆盖

| 页面 | 覆盖内容 | 优先级 |
|---|---|---|
| 首页 | 满屏轮播（API 驱动）+ 卡片流 + 顶栏/侧栏 | P0 |
| 详情页 | 多平台评分 + 剧照墙 + 演职员 + 相关推荐 + 外部播放器 | P0 |
| 媒体库页 | 网格/列表视图、筛选栏、字母索引 | P1 |
| 播放页 | 底部控制条、标题 | P2 |

## 详情页信息架构（参考 Emby-Javascript-Details 思路）

1. Backdrop 头图
2. 海报 + 标题 + 元数据
3. **多平台评分**：社区评分（主，大号）+ 影评人评分 + IMDb/TMDB/TVDB 外链
4. 标签 + 简介
5. 操作组（播放 / 继续 / 外部播放器 / 收藏）
6. **剧照墙**（Backdrop 横图横向滚动）
7. **演职员**（导演/主演头像行）
8. **相关推荐**（SimilarItems 海报行，点击跳转）

评分数据源：**默认零配置**，读 Emby 元数据已有评分与 ProviderIds；豆瓣作为可选增强。

## 便捷性设计

- 安装向导：逐项询问功能（回车 = 推荐默认）
- 备份回滚：部署前自动备份 `index.html`，卸载可恢复
- 网页设置中心：`settings.js` 注入右下角按钮，localStorage 持久化
- 一键升级：`update.sh` 拉新代码 + 重部署，配置保留
